Завдання №1. Макет власного сайту

Тип макету

Сайт MODHUB має адаптивний макет. Основа гумова: контейнер займає всю ширину екрана, але не більше 71,25rem (1140px), а колонки задані через Grid і Flexbox у частках (1fr) та відсотках. Поверх цього медіазапити перебудовують сітку для трьох груп пристроїв: десктопа, планшета й смартфона. Розміри шрифтів і відступів задані у відносних одиницях rem, тому інтерфейс масштабується разом з налаштуванням розміру шрифту в браузері.

Що вдосконалено в макеті

  • Навігація в шапці розширена до кількох пунктів і на смартфоні згортається в бургер-меню.
  • Додано блок інформаційних карток «Категорії модів» з адаптивною сіткою 4 → 2 → 1 колонка.
  • Таблиця популярних модів на смартфоні перебудовується: кожен рядок стає карткою.
  • Шапка закріплена вгорі сторінки під час прокручування.
  • Додано анімації: поява блоків при прокручуванні, плавне відкриття меню, ефекти наведення.

Файл js/main.js — відкриття бургер-меню та поява блоків при прокручуванні:

// ===== Бургер-меню =====
const burger = document.querySelector('.burger');
const nav = document.querySelector('.nav');

function closeMenu() {
    nav.classList.remove('nav--open');
    burger.setAttribute('aria-expanded', 'false');
    burger.setAttribute('aria-label', 'Відкрити меню');
}

burger.addEventListener('click', function () {
    const isOpen = nav.classList.toggle('nav--open');
    burger.setAttribute('aria-expanded', isOpen);
    burger.setAttribute('aria-label', isOpen ? 'Закрити меню' : 'Відкрити меню');
});

// закриваємо меню після вибору пункту
nav.querySelectorAll('a').forEach(function (link) {
    link.addEventListener('click', closeMenu);
});

// закриваємо меню, якщо екран став широким
window.addEventListener('resize', function () {
    if (window.innerWidth >= 768) {
        closeMenu();
    }
});

// ===== Поява блоків при прокручуванні =====
const blocks = document.querySelectorAll('.reveal');

const observer = new IntersectionObserver(function (entries) {
    entries.forEach(function (entry) {
        if (entry.isIntersecting) {
            entry.target.classList.add('is-visible');
            observer.unobserve(entry.target);
        }
    });
}, { threshold: 0.1 });

blocks.forEach(function (block) {
    observer.observe(block);
});

Адаптивна верстка

Метатег viewport

Без цього метатегу мобільний браузер показує сторінку як на екрані шириною близько 980px і зменшує її. З ним ширина сторінки дорівнює ширині пристрою, і медіазапити спрацьовують правильно.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Десктопна версія

Десктопна версія — це основні стилі файлу, написані без медіазапитів. Шапка — Flexbox з трьома частинами: логотип, меню та кнопки. Кнопки ігор, картки категорій і нижній блок розміщені через CSS Grid: repeat(6, 1fr), repeat(4, 1fr) та 1fr 1fr. Ширина контейнера обмежена max-width: 71.25rem, тому на великих моніторах рядки не розтягуються занадто сильно.

Планшетна версія

Для планшета використано медіазапит із логічним оператором and, який задає діапазон ширин. Сітки отримують менше колонок, а бічні відступи задано у vw, щоб вони пропорційно змінювались разом з екраном.

Відносні одиниці

  • rem — розміри шрифтів, відступи, ширина зображень і кнопок (1rem = 16px за замовчуванням).
  • % — ширина контейнера (width: 100%) та зображень (max-width: 100%).
  • vw — бічні відступи контейнера на планшеті й смартфоні, розмір заголовка через clamp(1.5rem, 1.2rem + 1.2vw, 1.75rem).
  • vh — мінімальна висота сторінки min-height: 100vh, щоб футер завжди був унизу, та висота меню в горизонтальній орієнтації.
  • em — відступ маркера в переліку переваг на сторінці Flexbox (margin-top: 0.45em).

Остання цифра студентського квитка — 2, тому виконано варіант 2: сторінка «Професія Java-розробник».

Як використано Flexbox

БлокВластивості
Переваги під заголовкомdisplay: flex; flex-wrap: wrap; елементи flex: 1 1 13rem — однакова ширина, перенос на новий рядок, коли місця менше ніж 13rem
Картки етапівКонтейнер flex-wrap: wrap, картка flex: 1 1 calc(25% - 1.5rem) — 4 в рядку. Сама картка теж flex-контейнер з flex-direction: column, текстова частина має flex: 1, тому темні блоки із зображеннями вирівнюються по нижньому краю
Номер етапуdisplay: flex; align-items: center; justify-content: center — цифра по центру кола
Рівні навчанняalign-items: center, зображення flex: 0 1 60%, текст flex: 1 1 40%
Підвалjustify-content: space-between — копірайт ліворуч, соцмережі праворуч

На планшеті (600–991px) картки етапів стають по дві в рядку, на смартфоні (до 599px) усі блоки вишиковуються в одну колонку. У рівнях навчання змінюється напрям flex-direction: column.

Висновки

Завдання №1. Макет власного сайту MODHUB вдосконалено та зверстано як адаптивний. Сайт має семантичну структуру header — main — footer, бургер-меню на смартфонах, адаптивні сітки на CSS Grid і Flexbox, які перебудовуються для трьох версій: десктопної (від 1024px), планшетної (768–1023px) та мобільної (до 767px). У медіазапитах застосовано логічні оператори and, кому та not, а також умови орієнтації пристрою. Розміри задано у відносних одиницях rem, %, vw, vh. Додано анімації появи контенту, відкриття меню та ефекти наведення. Файли розкладено по папках css, js, images, pages.

Завдання №2. Виконано таблична верстка за варіантом 6 і блокова верстка на плаваючих елементах за варіантом 7, кожна у фіксованому та гумовому виконанні. Порівняння показало, що фіксований макет простіше контролювати, але він не пристосовується до екрана, а гумовий займає всю доступну ширину, проте на дуже вузьких і дуже широких екранах стає незручним. Таблична верстка зручна для вирівнювання колонок за висотою, але змішує структуру сторінки з даними, тому для макетів сторінок не рекомендується. Блокова верстка на float вимагає додаткових прийомів (clear, overflow: hidden), які в сучасній верстці замінюють Flexbox і Grid.

Завдання №3. За варіантом 2 зверстано сторінку «Професія Java-розробник» засобами Flexbox. Використано flex-wrap, flex-basis, flex-grow, flex-direction, justify-content, align-items, вкладені flex-контейнери. Flexbox дозволив отримати картки однакової висоти та вирівнювання без фіксованих розмірів, а зміна кількох властивостей у медіазапитах перебудовує сторінку для планшета та смартфона.

Звітний HTML-документ доповнено розділом лабораторної роботи №3 і медіазапитами, завдяки яким він коректно відображається на планшетах і смартфонах.
